# 改動紀錄

## 1.8（2026-11-20）
- 「清空重來」和額度恢復後自動打的「繼續」：對你看過、顯示「閒置」的 agent 也送得出去（以前會被 hc 拒絕，「繼續」還會一直重試）
- omp 的「壓縮」：omp 壓縮時不回報狀態，送出 30 秒後當作壓縮好了，不再等 3 分鐘才說「沒等到結束」
## 1.7（2026-11-20）
- context 細項的「壓縮」在 agent 工作中也能按：先排隊（「已排隊，這輪結束後壓縮」），它停下來才送；送出後寫「壓縮中…」直到壓縮完
- 排隊或壓縮中再按（這裡或 Herdr Agents 清單的右鍵「壓縮」）只會說「已經在壓縮了」，一個 agent 一次只送一個 /compact
## 1.6（2026-11-19）
- agent 標題列的說明頁按鈕：agent 寫了新頁或改過一頁、這台電腦還沒看過，按鈕亮紅點（不用滑過去也看得到）；按下去直接開那頁
## 1.5（2026-11-18）
- agent 的 Kit 清單會顯示「被擋下的」項目和原因，可以直接收進 kit
- 「等你放行」的「放行並送出／不要」移到檔案清單上面，檔案很多時也按得到
- Windows 上不再試著讀只有 Mac/Linux 才有的資訊
## 1.4（2026-11-16）
- 方案用量在每個時段下面畫一條用量條（70% 換色、90% 變紅）
- 每個可以點的地方滑鼠移上去都會有反應
- agent 的標題列和 Agents 選單有「說明頁」按鈕，其他機器上的 agent 也行
- 面板重新載入、重開或重開 Herdr 後，回到你上次看的地方
## 1.3（2026-11-15）
- 「這次用了」：每個 agent 這次對話用了哪些 skill 和 MCP
- 「外掛」分頁；點一列看完整說明；作者出新版時可以「先不收」
- 「送出」會顯示每一步和進度條；送不出去的改動會立刻標紅並說原因
- 「等你放行」：被 commit hook 擋下的檔案等你按一下才送出
- 撞到用量上限時顯示幾點恢復，恢復後自動打「繼續」
- 也看得懂 Codex 和 omp 的背景工作、子 agent 和用量
## 1.2（2026-11-14）
- Agents 面板的「關係」：誰在跟誰說話、誰在等你、誰做完等你看、子 agent 在做什麼、時間軸
- 「提醒它回」和「不用回」：讓 agent 互相回覆
- 倉庫可以一次從一個網址收很多 skill，有進度條，依來源分組
- agent 視窗可以搜尋，「還沒用的」依來源分組
- agent 的標題列顯示它用 kit note 寫的進度
## 1.1（2026-11-13）
- 「各機器」：看每台電腦的 kit 缺什麼
- agent 有自己的動物機器人頭像
- 把 agent 拖到某個 space 就在那裡開；可以貼上 MCP 設定
## 1.0（2026-11-12）
- Kit 倉庫面板、Agents 面板和窗格標題列合成一個 mod
