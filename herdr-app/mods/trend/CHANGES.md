# 改動紀錄

## 1.6（2026-11-20）
- 分類重做：AI、軟體、硬體、3C、科技、科學、股票、財經、政治、社會、國際、娛樂、遊戲、體育、生活、搞笑、美食、旅遊、汽車；看中文標題，「趣聞」拆成生活和搞笑，八卦的新聞歸社會
- 上面的按鈕變成一排可以左右滑，分類照則數排；各站、排列、少的分類收進右邊「篩選」
- 卡片右上角：🔎 深入查、💬 三句話說明、☆ 收藏，卡片變矮；重複標題的那行不再顯示
- 選「⭐ 收藏」多一排分組（熱門照分類／主題、影片照主題），點一組只看那組
- 每張卡片寫發文的日期時間（11/20 14:26（3 小時前）），六個網站都有；還沒拿到發文時間的寫「上榜」加上榜時間
## 1.5（2026-11-20）
- 收藏影片的字幕會送到你的網站，手機聽歌也看得到字幕（每次排程抓幾支新的）
- 影片主題比對變嚴：標題要有主題超過一半的字（「JISOO earthquake」兩個字都要有）；一個字可以用 / 寫別名，例如「TWICE 子瑜/tzuyu/쯔위」
## 1.4（2026-11-18）

- 還沒同步出去的項目會先存起來，重開 Herdr 不會被蓋掉
## 1.2（2026-11-16）
- 「＋ 加主題」：每個主題約每小時搜 HN、PTT、Reddit、Dcard，有收藏、排序和網站顏色
- 影片排序（最多人看、最新上傳、最近找到、短的先、長的先），會記住
- 影片的「整理重點」放在播放器下面，可展開
- 切換分頁或關掉面板不會讓影片重來，回來時從原本的地方繼續
- 問 trend agent 時，正在看的影片會一起帶過去
