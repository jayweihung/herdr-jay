## 1.21（2026-11-27）

## 1.20（2026-11-27）
- 每個分頁自己一份（要 kit 0.17.0）：經過 `kit open` 開的分頁，Kit 視窗最上面多「這個分頁的（關掉就清掉）」，每一列可以「拿掉」；「還沒用的」多「加到這個分頁」，只加給這個分頁。要重開才讀得到的照樣問要不要重開接回，拿掉的送一則訊息叫它不要再用。不是經過 kit 開的分頁寫「這個分頁沒經過 kit 開」
- Agents 的「開啟」和把 agent 拖到 space（或「放到 space…」）改用 `kit open <工具> --agent <名字>` 開新分頁，開在 space 自己的資料夾，不再建 agent 自己的資料夾；那個 space 已經有它的分頁在跑就切過去（看 `kit tab list`）
- 分頁關掉，它那份就清掉（工具停了才 `kit tab rm`）；Herdr 一開，每台跑一次 `kit tab keep`
- 自動重開接回：經過 `kit open` 開的分頁改打 `kit open <工具> --tab-env HC_TERMINAL_ID -- <接回的參數>`，接回後分頁那份還在
- kit 比 0.17.0 舊：全部照舊（kit place、kit run）

## 1.15（2026-11-23）

## 1.14（2026-11-22）
- 修：Kit 視窗還是會「This view could not be re-rendered」：每畫一列都向 Herdr 重讀一次整份清單（每次約 15 毫秒），一次畫面要 120 毫秒以上；改成每次畫面只讀一次，量到 134 → 23 毫秒

## 1.13（2026-11-21）

- 每次 kit 改動只問一次：跳出小視窗「好／以後都直接做／這次不要」；選「以後都直接做」之後不再問，要改回先問，到那個 agent 的 Kit 視窗按「改回先問」

- 拿掉的（kit rm，整個帳號或資料夾；同步拿掉的也一樣）不重開、不用開新對話：開著的 agent 收到一則訊息「kit 剛從<這個資料夾／整個帳號>拿掉技能 X：之後不要再用它」（MCP：「…之後不要再用它的工具」；外掛：「…之後不要再用它的技能和指令」；規則照舊），每種一則；做完那行寫「t3 已告訴它拿掉了」。例外：拿掉的外掛有 hook 時，Claude Code 送 /reload-plugins，omp、Codex 照舊重開接回

- 它停下來了、但你正在那一格（Herdr 在最前面）時，標題列寫「你在這格：切到別格就重開接回」，不再寫「等它停下來」（Herdr 讀不到你最後一次按鍵的時間，所以只能等你切走）
- 接回後程式先問你問題（例如 Claude 的「Allow external CLAUDE.md file imports?」、信任這個資料夾嗎）：不替你回答，標題列寫「接回了，在等你回答它的問題」，通知「<agent> 接回了，但它在問你：<問題>。請到那一格回答」；你回答、出現它平常的輸入框後就算接回
- agent 的 Kit 視窗：按「從資料夾拿掉」「加到這個資料夾」之後，清單馬上重讀；之前讀到一半卡住（或很慢）的那次不再擋著，它讀完的舊結果也不會蓋掉新的；⟳ 在轉的時候也能按
- 「kit 的改動要重開才讀得到」小視窗跳出來時，Kit 視窗和用量視窗會自己關掉，不再擋住它一半（Herdr 的小視窗一定在彈出視窗下面）；Kit 視窗裡 kit 的結果訊息還在，再打開就看得到
- agent 的 Kit 視窗按「同步」：除了同步這台，也讓這個 agent 跟上。同步完再讀一次它的清單，要打 /reload-plugins 的送一次，要重開才讀得到的（規則、MCP 等）跳出「要重開才讀得到」小視窗問一次；同步本身已經對它送過、問過的不再重複；同步後還是舊的、要開新對話的只寫出來。上面一行寫做了什麼：「同步好了；t3：送了 /reload-plugins，要重開接回（在跳出的視窗選）」或「同步好了，這個 agent 全部最新」
- 最上面那行改成指向按鈕：同步能全部弄好時寫「5 項舊版：按同步」；有同步救不了的（這次對話用過舊版的技能）才寫「…項開新對話才會讀到」
- 同一台、一模一樣的 kit 查詢（kit list、kit used、kit status …）同時只跑一個，大家共用它的結果：同一個 agent 的 Kit 視窗開好幾次、按 ⟳、每個視窗的標題列，不再各叫一次讓很忙的電腦更慢；kit 改動（加上、拿掉、同步）之後的查詢一定重新跑，改動前那次的舊結果不會蓋掉新的；標題列上一次還沒讀完就不再開新的一次
