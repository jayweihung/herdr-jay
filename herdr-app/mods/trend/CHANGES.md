# 改動紀錄

## 1.5（2026-11-20）
- 收藏影片的字幕會送到你的網站，手機聽歌也看得到字幕（每次排程抓幾支新的）
## 1.4（2026-11-18）
- 資料夾位置照系統的設定找，Linux 上改過設定資料夾也找得到
## 1.3（2026-11-17）
- 熱門可以同步到你自己的網站
- 還沒同步出去的項目會先存起來，重開 Herdr 不會被蓋掉
## 1.2（2026-11-16）
- 「＋ 加主題」：每個主題約每小時搜 HN、PTT、Reddit、Dcard，有收藏、排序和網站顏色
- 影片排序（最多人看、最新上傳、最近找到、短的先、長的先），會記住
- 影片的「整理重點」放在播放器下面，可展開
- 切換分頁或關掉面板不會讓影片重來，回來時從原本的地方繼續
- 問 trend agent 時，正在看的影片會一起帶過去
## 1.1（2026-11-16）
- 「影片」分頁：你自己的 YouTube 搜尋，點了就在面板裡播
- 「報告」分頁：看 trend agent 寫的報告
- 列出 HN、Digg、Reddit、PTT、Dcard、Threads 首頁的熱門，依主題分類
- 看出哪些正在往上衝、哪些剛上榜
## 1.0（2026-11-16）
- 熱門按鈕和面板：現在大家在聊什麼，每小時更新，不花 token；可以「深入查」或問 trend agent
