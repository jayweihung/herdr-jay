# 改動紀錄

## 1.4（2026-11-16）
- 「深入 Review」：先下載這個 change 的程式碼，再讓 agent 深入審查
- 面板重新載入、重開或重開 Herdr 後，回到你上次看的地方
- 「還有 N 串已解決的」可以用滑鼠點開
## 1.3（2026-11-15）
- 也能問 Codex 或 omp 的 gerrit agent，並可選 kit 的 gerrit agent 用哪個工具開
## 1.2（2026-11-14）
- 「在 nvim 看」：把一個 patch set 的檔案打開在 nvim 裡 review，可選幾行提問、回覆、看建議修改和舊版的討論串
- 「切到 nvim」只在 review 分頁的 nvim 還開著時出現
- 打開的 change 會顯示 nvim 剛存的草稿，文字保留換行
- 作者才有的按鈕只出現在你自己的 change；投票投在你正在看的那一版

- Jenkins ▶ 只出現在你自己的 change
